# AGENTS.md - EMG-Analysis Repository Guide

## Project Overview
EMG signal analysis using NinaPro databases (DB1, DB2, DB3, DB4, DB5, DB7). Processes raw EMG into feature sets (Hilbert envelope, NoEnvelope, mixed) and creates consolidated datasets for intact (107 subjects) vs amputated (13 subjects) groups.

## Key Commands
```bash
# Activate venv
source venv/bin/activate

# Run notebooks (Jupyter)
jupyter lab notebooks/

# Install dependencies
pip install -r requirements.txt
```

## Data Structure
```
data/
├── master/           # Consolidated outputs (created by 01_create_datasets.ipynb)
│   ├── intact_subjects.csv, amputated_subjects.csv
│   ├── intact_signals.csv, amputated_signals.csv
├── metadata/         # Raw subject metadata per DB
├── processed/        # Feature CSVs per DB (Hilbert, NoEnvelope, mixed)
│   └── features_mixed_NinaProDB{1-7}_200ms.csv  # 8 channels × 26 features = 208 signal cols + 5 metadata
└── raw/              # (not tracked)
```

## Notebook Pipeline (run in order)
1. **01_create_datasets.ipynb** - Merges processed DBs into master intact/amputated CSVs (channels 1-8 only)
2. **02_metadata_intact_eda.ipynb** - EDA on intact subject metadata (demographics, BMI, DB distribution)
3. **02.2_metadata_amputed_eda.ipynb** - EDA on amputated metadata (amputation cause, phantom limb, DASH score, prosthesis use)
4. **03_signals_eda.ipynb** - *Pending*

## Key Conventions
- **Channels**: Only 1-8 used (DB4 has 12, trimmed for consistency)
- **Window**: 200ms windows, features per channel (208 signal columns)
- **Mixed features**: MAVS, MNF, SSC, TD, WL, ZC, mDWT from NoEnvelope; others from Hilbert
- **Merge keys**: subject, stimulus, window_index, window_size_samples, window_size_ms

## Dependencies (requirements.txt)
pandas, numpy, matplotlib, seaborn, scipy, scikit-learn, jupyter, ipykernel
