# AGENTS.md - EMG-Analysis Repository Guide

## Project Overview
EMG signal analysis using NinaPro databases (DB1, DB2, DB3, DB4, DB5, DB7). Processes raw EMG into feature sets (Hilbert envelope, NoEnvelope, mixed) and creates consolidated datasets for intact (107 subjects) vs amputated (13 subjects) groups. Includes data normalization using Box-Cox and Yeo-Johnson transformations.

## Key Commands
```bash
# Activate venv
source venv/bin/activate

# Run notebooks (Jupyter)
jupyter lab notebooks/

# Install dependencies
pip install -r requirements.txt
```

## Notebook Pipeline (run in order)
1. **01_creates_db_merge.ipynb** - Loads/validates 4 master CSVs (intact_signals, intact_subjects, amputated_signals, amputated_subjects)
2. **02_creates_dataset_intact.ipynb** - Builds intact dataset from mixed features (output: ~881K rows, 216 cols)
3. **03_intact_database_analysis.ipynb** - EDA on intact dataset (output: ~407K rows, 68 cols)
4. **transformation.ipynb** - Applies PowerTransformer (Box-Cox and Yeo-Johnson) to normalize features
5. **comparison.ipynb** - Compares transformation methods and outputs

## Key Conventions
- **Channels**: Only 1-8 used (DB4 has 12, trimmed for consistency)
- **Window**: 200ms windows, features per channel (208 signal columns in raw mixed)
- **Mixed features**: MAVS, MNF, SSC, TD, WL, ZC, mDWT from NoEnvelope; others from Hilbert
- **Merge keys**: subject, stimulus, window_index, window_size_samples, window_size_ms
- **Stimulus codes**: [0, 22, 25, 27, 30, 31, 37, 40]
- **Transformations**: Box-Cox (requires positive values), Yeo-Johnson (handles negatives)
- **Language**: Project uses Spanish naming conventions
